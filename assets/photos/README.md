# 示例照片

这些 PNG 是项目用 Pillow 以几何图形/渐变生成的演示图片（800×450），**不包含**
第三方照片、肖像或商标。许可：CC0 1.0。

- 相册默认扫描本目录（可用 `BOARD_APP_PHOTO_DIR` 覆盖）。
- 替换成自己的照片时，保持 `.png` / `.jpg` / `.jpeg` / `.bmp` 扩展名即可。
- 编辑保存时，默认在**原图所在目录**生成 `<原名>_edited_时间.png`，不会覆盖这里的原图。
- 旧版本的 `data/edited/` 文件仍保留，但界面不再单独提供“已保存”入口。
- 生成脚本是一次性工具，未纳入仓库；如要重新生成，可使用任意
  Pillow/绘图脚本输出同名文件。
